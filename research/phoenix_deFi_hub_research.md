## What Phoenix Does
Phoenix DeFi Hub is building the definitive decentralized finance (DeFi) ecosystem on Stellar's Soroban smart contract platform. Rather than launching isolated protocols, Phoenix is architecting a suite of synergistic DeFi applications where each protocol drives value to the others, creating a self-reinforcing DeFi hub.

## Technical Architecture
Phoenix is built entirely on Soroban, Stellar's Rust-based smart contract platform:
- Language: Rust (compiled to WASM)
- Platform: Soroban on Stellar
- Contract Type: AMM DEX with constant product formula

Key Features:
- Permissionless liquidity pool creation
- Cross-contract call optimization (ultra-fast, low-cost)
- Minimal binary sizes for reduced transaction fees
- Full test coverage with Soroban testutils

## Stellar Integration
## Why Stellar?
Phoenix chose Stellar for several strategic reasons:
1. Stablecoin Focus: Stellar's native support for USDC, EURC, and other stablecoins makes it ideal for DeFi onboarding
2. On/Off-Ramps: Integration with MoneyGram Access, Circle Alliance, and Stellar Anchors enables fiat-to-crypto flows
3. Low Costs: Sub-cent transaction fees make micro-transactions viable
4. Speed: 5-second finality enables real-time trading
5. Rust + WASM: Soroban's developer experience with efficient storage and cross-contract calls
